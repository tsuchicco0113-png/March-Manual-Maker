# Marché Manual Maker

マルシェ・ハンドメイド出店向けの「取扱説明書ジェネレーター」。ブラウザだけで動き、`window.print()` で A4 / カード用紙にベクター品質で印刷・PDF保存できます。

## 使い方
1. `index.html` をブラウザで開く（`assets/` フォルダも同じ場所に置く）
   - インターネット接続が必要です（React・QR生成・フォントをCDNから読み込みます）
   - zipの中から直接開かず、必ず展開してから開いてください
2. 左ペインで内容を編集し「PDF保存（印刷）」
3. 印刷画面で 用紙A4・倍率100%・余白なし を選択

GitHub Pages で公開する場合: Settings → Pages → Branch: `main` / root。

## 主な機能
- レイアウト: A4四つ折り（十字折り）/ A4 1枚（ブロック自由配置）/ 名刺10面 / ポストカード4面
- 面ごとの天地反転、仕上がり3Dプレビュー、拡大縮小
- 画像（位置・ズーム・フチなし）、QRコード×2、注意ピクトグラム、ロゴ
- フリー配置デコ画像（移動・拡大・回転、所属面に追従）
- 両面印刷（ロゴ総柄 / サンクスメッセージ）、印刷ズレ補正
- 手描き風ゆらぎ・かすれ・にじみ、紙の質感、マステ/チェキ風、スタンプ
- 複数商品の保存、JSON書き出し/読み込み、リンク集HTML書き出し

## データ
編集内容はブラウザの localStorage に保存されます。バックアップは「商品データ → 書出」でJSONに。
